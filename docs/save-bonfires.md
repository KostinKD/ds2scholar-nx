# Костры в сохранении SotFS 360

`tools/unlock_bonfires.py` работает только с копией большого файла персонажа
`USER_DATA0b`–`USER_DATA14` (499 976 байт). Профиль персонажа лежит отдельно:
первому соответствует `USER_DATA01` + `USER_DATA0b`, второму `02` + `0c`, и т.д.
PC-контейнеры `.sl2` не принимаются.

```powershell
python tools/unlock_bonfires.py out/backup/USER_DATA0b --output out/modified/USER_DATA0b
python -m unittest discover -s tools/tests -p test_unlock_bonfires.py -v
```

Инструмент проверяет размер, MD5 (последние 16 байтов), ровно две одинаковые таблицы
77 ID, согласованность флагов и допустимость значений. Меняет только нулевые
байты «костёр зажжён» на 1 в обеих таблицах и пересчитывает MD5. Интенсивность
костров, события мира, боссы, NPC, инвентарь и профиль не меняются. Входной файл
не перезаписывается; существующий выходной файл тоже не заменяется.

Доказательство формата Xbox: в seed Хейда массивы BE u16 начинаются в `0x282C8`
и `0x2E324`, ёмкость 256; флаги лежат на `anchor+512`, интенсивность — на
`anchor+768`. Зажжены только ID 2650 (Междумирье), 4650 (Маджула), 31655 (Хейд).
Все 77 ID сверены с обеими таблицами. В актуальном сейве Switch от 2026-10-27
структуры и контрольные суммы совпали с этим форматом у всех четырёх персонажей.
Независимое описание относительной структуры PC:
[Bonfires в er-save-manager](https://github.com/Hapfel1/er-save-manager/blob/main/src/er_save_manager/games/DS2/save.py).
Смещения профиля и PC-контейнера из этого источника на Xbox не переносились.

Зажжённые костры открывают точки перемещения. Инструмент не устанавливает
флаги прохождения боссов и не открывает все двери/сюжетные события.

Перед установкой: закрыть игру, скачать полный сейв, сверить изменяемые файлы
с резервной копией. Загрузить только нужные файлы через `switch_upload.py --backup`
в `/switch/ds2scholar-nx/ds2/B13EBABEBABEBABE/465307E4/00000001/-GAME_0000`.
После загрузки скачать их обратно и сравнить SHA-256. Загружать сейв, пока игра
работает, нельзя: она может сохранить старое содержимое поверх изменений.
