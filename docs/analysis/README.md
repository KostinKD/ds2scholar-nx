# Анализ

Здесь хранятся подтверждённые факты об исполняемом файле DS2 SotFS (факты обычной DS2 — docs/ds2-nx/analysis/, для SotFS их нужно подтвердить заново). Каждый факт сопровождается доказательством:
адрес, листинг или вызывающие функции, чем подтверждено (листинг, запуск, сравнение с другой игрой).
Неподтверждённое помечать **[не подтверждено]**.

Файлы, которые появятся по ходу работы:

| Файл | Что | Этап |
|---|---|---|
| xex.md | Title ID, TU, хеш default.xex, секции, импорты, доп. модули | 1 |
| xdk.md | Версия XDK (из import libraries XEX), что от неё зависит | 1 |
| files.md | Формат архивов игры, видео, звука; что реально читается при старте | 1 |
| manifest-notes.md | Пояснения к нетривиальным записям app/ds2_manifest.toml | 2 |
| threads.md | Потоки игры: имя, роль, приоритет, найденные busy-wait'ы | 3, 5 |
| d3d.md | Адреса D3D-функций, раскладка device, смещения VS/PS | 4 |
| shaders.md | Источники шейдеров, неопознанные загрузки, обёрнутые шейдеры | 4 |
| hot-functions.md | Горячие функции по профилю консоли, статус нативных версий | 5 |
