# GPU: облегчённые шейдеры и 32-битные цели 7e3

> Исполнение в текущей сессии по запросу владельца «Давай, 1 и 6».

Цель: подготовить раздельный A/B тяжёлых шейдеров и уже существующего B10G11R11.
Исходное поведение по умолчанию сохраняется; новые варианты — эксперимент, требуют проверки картинки.

Подход: специализация SPIR-V по свободному биту 23 SpecId 0; маска cvar
`ds2_shader_light_mask` (0 по умолчанию), выбор только по четырём подтверждённым хешам.
1=PS31 (один кадр частицы), 2=PS385 (линейная кривая тумана),
4=PS421 (цвет обломков через умножение вместо overlay), 8=PS961 (первый слой материала).
Отдельные биты позволяют проверять одно изменение за раз. Упрощённые варианты меняют картинку.
FP16 не входит в этот эксперимент. B10G11R11 — отдельные конфиги; найденный в runtime
пропуск depth→R11 закрывается вариантом существующего шейдера экспорта за прежним ключом.

Альтернативы: общая замена точности слишком широка; ручные копии HLSL невоспроизводимы
и содержали бы игровые данные. Поэтому в git только проверяемый преобразователь и хеши;
HLSL/SPIR-V/пакеты остаются в out. Старый пакет без бита должен давать явное предупреждение и baseline.

- [x] Тесты преобразователя: неизвестный/изменённый источник отвергается, baseline сохранён,
      для каждого целевого хеша сделано ровно одно ожидаемое преобразование.
- [x] Преобразователь и runtime cvar, поддержка специализации только при наличии варианта в пакете.
- [x] DXC всех четырёх вариантов: original, forced-off, forced-on, specialization; отчёт стоимости
      по инструкциям SPIR-V (не обещание времени GPU). Пакет через --replace-exact поверх v8.
- [x] Сборка PC и Switch; PC A/B muted+minimized с копией сейва. Проверка NRO — отметка ниже.
- [x] Раздельные конфиги baseline / mask=1,2,4,8 / r11. FTP дважды timeout8s;
      не заменять NRO при запущенной игре. При недоступной консоли сохранить готовые артефакты.
- [x] Журнал с результатами, ограничениями и следующим консольным замером; коммит этой ветки.

Проверки: точное сохранение ветви baseline; корректный pipeline/prewarm key; отсутствие
смешивания r11 и shader-mask в A/B; исходные пакеты и сейвы не заменять; чужие правки не коммитить.

Решение: использовать существующий checkout с новой веткой, поскольку сборочные каталоги,
PGO, входы шейдеров и сейвы привязаны к этому абсолютному корню. Отдельное рабочее дерево
потребовало бы второй полной сборки; чужой манифест исключён из коммита.

Проверка 2026-10-25: DXC генерирует локальный OpBitwiseAnd для нового бита; существующий
generic detector его не узнавал. Добавлен отдельный Ds2ShaderLightSupported с обеими формами
AND, regression RED→GREEN, проверены все четыре реальные SPIR-V. Generic detector не изменён.
Пробная PC-сессия со старым детектором: fallback и guest AV sub_82F37B60 при входе в мир;
это не проверка облегчённого шейдера. С исправленным детектором mask15 прошёл244s;
PS31/385/961 активны, PS421 в этом виде не встретился.

Дополнение п.6: baseline depth exports3322/10s, R11 3000/10s и capped unsupported depth→color.
ConvertDepthEDRAM4 не принимал B10G11R11. Добавлен DST_FMT вариант прежнего compute shader,
pipeline4 только под g_host_7e3_r11g11b10, прежние индексы0..3 сохранены. Тест компилирует
реальный GLSL и проверяет storage-image формат2/8 (RED→GREEN). Повторный PC-прогон244s:
skipped0, guestAV0, exports3322/10s и transferred37552, как у baseline. Явных повреждений нет.
Для финальной Switch-ссылки LTRANS jobs2→5 (только build cache; RAM23,8 ГБ, свободно13,9).

Финальная проверка NRO относительно spike2: passed; halt1 known, vectorFMA6 как у эталона.
Артефакты `out/gpu_ab` и `out/nx/keep/sotfs_gpu_lite1.*`, метка gpu lite1.
