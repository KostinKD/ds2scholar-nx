# Release 1.10.0-access1

This experimental release uses a single initial master commit, tagged v1.10.0-access1.

- Player package: ds2scholar-nx-1.10.0-access1-home.zip.
- Optional developer profile: ds2scholar-nx-pgo-v4-1.10.0-access1.zip.
- Source snapshot: ds2scholar-nx-source.zip.
- Verify downloads against SHA256SUMS.txt attached to the release.

Game data, private keys and saves are excluded. Use your own Xbox 360 SotFS
GoD copy and Compatibility Pack 4. See the player guide for installation.
HOME boot, saves and the selected cover were confirmed on the owner's console.
Fresh SD installation, a full playthrough and all DLC remain unverified.
Game source code and runtime binaries are unchanged by this publication cleanup.

For rebuilding, clone the repository and use the optional PGO package from this
release. Its manifest references the new initial master commit. The source ZIP
is a snapshot; PGO installation uses Git revision checks.
