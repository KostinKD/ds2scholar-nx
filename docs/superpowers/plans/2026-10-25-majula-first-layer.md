# Первый слой материала Маджулы — gpu lite2

Продолжение авторизованного пункта1: выбирать тяжёлые шейдеры по логам и делать варианты
за ключом. PS385/mask2 в ds2_091 дал35,3fps/28,4ms, как baseline; переключение подтверждено.
Новая ветка `perf-majula-first-layer`, прежний каталог для абсолютных путей SDK/PGO/сборок.

Доказательство выбора: ds2_087/088/091, ведущие проходы VS135/PS95 и VS135/PS1255.
Хеши `0feaa33b192cdc87` и `caee55f06defe9d8`. Это метки проходов, не индивидуальные замеры PS.
В HLSL PS95 смешивает diffuse/bump-канал двух слоёв по TEXCOORD7.w; PS1255 смешивает
две восстановленные нормали по тому же TEXCOORD7.w. Общий вариант оставляет первый слой
цвета и нормали, сохраняя освещение, туман, dither и альфу. Меняет качество материалов.

Подход: прежний SpecId0/bit23, новый mask bit16 выбирает оба точных хеша. Два отдельных бита
не нужны: это одно изменение материала в цветном проходе и prepass нормалей. Первые четыре
варианта и R11 сохраняются, default mask0. Поднимать глобально FP16/качество не будем.
Исходные ветви сохраняются дословно; HLSL/SPIR-V/пакеты только в out.

- [x] RED→GREEN: тесты преобразователя для двух хешей и общий mask16, C++ mapping.
- [x] PS95: в light-ветви diffuse остаётся первым без lerp; bump-канал также первым.
      PS1255: нормаль до нормализации берётся из первого восстановленного вектора.
      SHA-256 источников закреплены, неожиданные места правки отвергаются.
- [x] DXC original/off/on/spec для6 шейдеров; off opcode histogram совпадает с original,
      on уменьшает инструкции и число выборок. C++ probe видит bit23 во всех6 SPIR-V.
- [x] PC сборка и masked muted/minimized запуск на копии сейва; Switch LTO+PGO5jobs,
      check_switch_build относительно проверенного gpu lite1. Ревью изменений.
- [x] Артефакты gpu lite2, baseline и mask16 отдельно, старые артефакты не заменять.
