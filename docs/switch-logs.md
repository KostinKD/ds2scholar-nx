# Получение логов с Switch

Когда задача требует актуальных логов игры с консоли (например, анализ падения,
графических ошибок или профиля производительности), Codex и Claude сначала сами
запускают сборщик из корня `ds2scholar-nx` и дожидаются завершения передачи.
Не просите владельца вручную скачивать и перекладывать логи. Сборщик подключается
к FTP на `192.168.1.76:5000` (без логина и пароля), рекурсивно читает
`/switch/ds2scholar-nx/logs`, сохраняет файлы в `out/switch_logs/latest/`
и архивирует изменившиеся версии в `out/switch_logs/history/`. Он только читает
SD-карту и не меняет файлы игры. На FTP-сервере все даты файлов отображаются как
1970 год, поэтому новые версии определяются сравнением содержимого.

Один сбор перед разбором логов:

```powershell
python tools/switch_logs.py --host 192.168.1.76 --port 5000 --remote /switch/ds2scholar-nx/logs --once
```

Для продолжительного наблюдения запустите команду без `--once`; она сама
повторяет сбор и переподключается при временной недоступности консоли. После
завершения выгрузки сначала изучайте самые свежие файлы в `out/switch_logs/latest/`.
Переносите их в `logs/` или отчёты только если формат работы по задаче требует
коммита или отдельной выборки. Не выводите в отчёты SSID и пароль Wi-Fi.
Если FTP недоступен или указанная папка отсутствует, сообщите фактическую ошибку
и продолжайте с уже имеющимися локальными логами.

## Загрузка сборок на консоль

Через тот же FTP агенты сами кладут на консоль NRO, `ds2.toml` и пакет шейдеров —
владельца копировать файлы не просят. Запуск из PowerShell (Git Bash переписывает
`/switch/...` в путь Windows):

```powershell
python -I tools/switch_upload.py --backup out\nx\ds2.nro app\ds2_switch.toml=ds2.toml
```

Аргумент — `ЛОКАЛЬНЫЙ[=ИМЯ_НА_КОНСОЛИ]`, папка по умолчанию `/switch/ds2scholar-nx`
(`--remote`). Файл пишется как `ИМЯ.part`, размер сверяется, потом он переименовывается
поверх старого — оборванная передача не оставит битую NRO. `--backup` сначала
скачивает заменяемый файл в `out/switch_upload/backup/`. Пока игра запущена, NRO не
заменять (владельцу — выйти в hbmenu). В отчёте указать, что теперь на консоли:
метку сборки в hbmenu и отличия конфига.
